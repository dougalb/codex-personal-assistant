# Personal Assistant Weekly Review

Review active work, waiting-on, open questions, recent outputs, automation runs, source watermarks, and stale knowledge concepts. Create a reviewable weekly output with progress, risks, next actions, stale concepts, and unresolved contradictions. Route durable learning through verification and the curator; validate and locally checkpoint only when safe. Never send, publish, purchase, delete, alter credentials, or finalize external changes.
