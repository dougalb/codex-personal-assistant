# Personal Assistant Weekly Review

Review active work, waiting-on, open questions, recent outputs, automation runs, source watermarks, stale and expired memory concepts, pending sensitive approvals, and the 30-day attention calibration metrics. Create a reviewable weekly output with progress, risks, next actions, stale concepts, unresolved contradictions, missed-important-item rate, correction rate, and whether interruption reductions remain within guardrails. Route durable learning through verification and the curator; validate and locally checkpoint only when safe. Never send, publish, purchase, delete, alter credentials, or finalize external changes.
