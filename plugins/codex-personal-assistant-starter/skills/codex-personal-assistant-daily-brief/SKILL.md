# Personal Assistant Daily Brief

Load action policy, active work, waiting-on, open questions, today’s commitments, and `knowledge/index.md`. Read eligible connected sources, identify schedule conflicts, deadlines, decisions, and the three highest-leverage next actions. Create a concise dated brief in `outputs/` with source locators and confidence on material claims. Reversible drafts are allowed; never send or finalize an external action. Log the run compactly.
