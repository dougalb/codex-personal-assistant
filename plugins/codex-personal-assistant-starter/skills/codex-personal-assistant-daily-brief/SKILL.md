# Personal Assistant Daily Brief

Load action policy, data policy, active work, waiting-on, open questions, today’s commitments, attention calibration, and `knowledge/index.md`. Read only sources authorized for the requested brief, identify schedule conflicts, deadlines, decisions, and the three highest-leverage next actions. Create a concise dated brief in `outputs/` with `Needs you`, `Handled or staged`, and `Watching or suppressed` sections, source locators, confidence, and memory IDs on material claims. Record content-free attention events when the user accepts, dismisses, corrects, or later identifies a missed important item. Reversible drafts are allowed; never send or finalize an external action. Log the run compactly.
