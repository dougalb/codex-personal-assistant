# Morning brief scheduled-task prompt

Run locally in this assistant repository using Sol Medium. Load `context/`, `state/active-work.md`, `state/waiting-on.md`, `state/open-questions.md`, `state/attention-calibration.json`, and only `knowledge/index.md` before retrieving deeper concepts as needed. Read only sources authorized by the data policy, create a concise reviewable brief in `outputs/` with `Needs you`, `Handled or staged`, and `Watching or suppressed` sections, record content-free attention events, and log the run. You may create reversible drafts, but never send, publish, purchase, alter credentials/security, delete, or make a final external change.
