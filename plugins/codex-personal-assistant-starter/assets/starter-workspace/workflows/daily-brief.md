# Daily Brief Workflow

## Goal

Create a concise source-grounded start-of-day brief without making final external changes.

## Steps

1. Load action policy, data policy, active work, waiting-on, open questions, attention calibration, and `knowledge/index.md`.
2. Read only eligible sources, including today’s calendar commitments.
3. Separate `Needs you`, `Handled or staged`, and `Watching or suppressed`; flag conflicts, deadlines, decisions, and the three highest-leverage next actions with source locators and memory IDs.
4. Save `outputs/YYYY-MM-DD-daily-brief.md`, record content-free attention events, and append a compact run record.
5. Create only reversible drafts automatically. Ask once before any final external action or sensitive-memory approval.
