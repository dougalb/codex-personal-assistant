# Document Review Workflow

## Goal

Review a document for clarity, risks, missing decisions, and next actions.

## Steps

1. Identify the source document and review goal.
2. Extract key facts, decisions, assumptions, and open questions.
3. Review for security, privacy, operations, ownership, cost, resiliency, and migration risk when relevant.
4. Produce findings first, then recommendations.
5. Save the result in `outputs/YYYY-MM-DD-document-review.md`.
