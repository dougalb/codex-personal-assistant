# Communication Draft Workflow

## Goal

Draft a message for review without sending it.

## Steps

1. Identify audience, channel, and desired outcome.
2. Gather approved source material.
3. Draft the message.
4. Mark any unverified claim with `[confirm ...]`.
5. Save the result in `outputs/YYYY-MM-DD-communication-draft.md`.

## Rule

The assistant drafts only. The user sends or publishes from the destination app.
