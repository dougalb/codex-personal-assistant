# Getting Started

This folder is the local home for your Codex Personal Assistant.

## Start here

1. Open this folder in Codex.
2. Start a new thread.
3. Ask: `Use $codex-personal-assistant-bootstrap to finish my first-run setup.`
4. Answer the setup questions in plain English. Short answers are fine.

## What the assistant is building

The assistant uses local files to remember how you work:

- `context/` stores stable background, source rules, and stakeholder notes.
- `state/` stores current work, open questions, approvals, and waiting-on items.
- `workflows/` stores repeatable procedures.
- `outputs/` stores drafts and summaries you can review.

## First useful workflows

Pick one small workflow first:

- Daily brief.
- Meeting prep.
- Document review.
- Communication draft.
- Weekly review.

Do not try to automate everything on day one. The goal is to create one useful result, correct the files, and let the assistant get better with each run.
